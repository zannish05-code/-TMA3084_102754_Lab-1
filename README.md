Pizza Order Calculator
TMA3084 SELAB - Lab 1
Description
This Dart program calculates the total payment for pizza orders using a switch statement and a while loop.
Pizza Prices
Small: USD 5
Medium: USD 7
Large: USD 10
Features
Select pizza size
Enter quantity
Calculate total payment
Validate user input
Allow continuous ordering
How to Run
Open the project in VS Code.
Open the terminal.
Run: dart run pizza_order.dart
